# Recto compatibility fixture

`recto-marks.pdf` is contributor-original test material generated by the unchanged
Recto PDF creation/watermark implementation at baseline
`9fded4f241f8b457dd68e751404c9b59afbeab04`. Stage 1 identity code does not modify
that writer. It contains ordinary text, a watermark, `/PCMark` and `%Recto` wrappers.
No third-party font program or private user content is embedded. Workspace licensing applies.

SHA-256: `45874e7000b812b21f61ae9aefafe06f4ac8e5b3771a1f478175c7da24e539f5`

The reproduction tool is `cargo run -p recto-engine --example recto_compat_fixture --locked`.
Do not regenerate automatically: the committed bytes are the compatibility boundary;
new writers must read them. The tests additionally use the existing signed PDF and
PKCS#12 test identities whose provenance is documented in
`crates/sign/tests/data/README.md`.
