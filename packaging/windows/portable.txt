Pagic portable mode

While this file sits next to pagic.exe, Pagic keeps its settings, log files, crash-recovery
autosaves and new digital IDs in the PagicData folder beside it, and writes nothing to
%APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move Pagic with its settings.

Delete this file to use the normal per-user folders (%APPDATA%\Pagic and
%LOCALAPPDATA%\Pagic) instead. If PagicData can't be written (for example on a read-only
drive), Pagic says so and uses the per-user folders instead.
